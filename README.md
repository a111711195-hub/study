## **virtual (가상 메서드)**

**부모 클래스의 매서드 앞에 붙여 자식 클래스에서 원하는 방식대로 덮어쓰도록 허용하는 키워드**

* **부모 클래스에 몸통{} 이 있어야 함**
* **자식 클래스에서 덮어쓸 때 override 키워드 작성**
* **override 하지 않을 시 부모 클래스에 작성된 대로 실행**

## **Abstract (추상화)**

**복잡한 세부 구현은 감추고, 핵심 기능과 역할만 뽑아내어 단순화하는 개념**

* **부모 클래스를 선언만 함**
* **자식 클래스에 override 필수**
* **추상 클래스 내부에서만 가능**
