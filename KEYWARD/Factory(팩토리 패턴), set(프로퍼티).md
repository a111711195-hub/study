# **Factory (팩토리 패턴)**

* #### **객체 생성과 사용을 분리해 결합도를 낮추고, 새 타입이 추가될 때 기존코드를 덜 건드리게 함**
* #### **단순 팩토리(Simple Factory), 팩토리 메서드 패턴(Factory Method), 추상 팩토리 패턴(Abstract Factory)으로 나뉨**
* #### **게임에서 몬스터, 아이템, 무기 생성이나 다른 결제/알림 객체를 생성할 때 자주 쓰임**



# **set (프로퍼티)**

* #### **잘못된 값이 들어올 때 0으로 보정하거나 예외를 던지는 등 데이터 보호와 검증이 가능**
* #### **값이 바뀔 때 상태 갱신이나 알림 같은 부가 로직을 넣을 수 있음**
* #### **내부 변경만 허용이거나 초기화 시에만 설정으로 보호할 수 있음**
