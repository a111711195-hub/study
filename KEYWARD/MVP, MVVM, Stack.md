# MVP(Model-View-Presenter)

###
- UI와 비즈니스 상태 로직을 분리하는 아키텍처 패턴
- C#에서는 데이터 바인딩 지원 여부에 따라 선택지가 갈림
- 중간 계층 Presenter : View와 1:1에 가깝게 연결되며, View의 이벤트를 받아 Model을 조작한 뒤 View의 메서드나 인터페이스를 직접 호출해 화면을 갱신


# MVVM(Model-View-ViewModel)


- UI와 비즈니스 상태 로직을 분리하는 아키텍처 패턴
- C#에서는 데이터 바인딩 지원 여부에 따라 선택지가 갈림
- 중간 계층 ViewModel : View를 직접 참조하지 않고 상태와 명령을 노출하며, 데이터 바인딩을 통해 View가 변경 사항을 스스로 반영


# Stack

###
- 후입선출(LIFO) 원칙으로 동작하는 자료구조, 가장 나중에 들어온 데이터가 가장 먼저 나감 (A, B, C) => (C, B, A)
- 커맨드 패턴에서 실행 취소(Undo) 기록을 쌓을 때 이 원리를 활용
- 실행 취소(Undo), 브라우저 뒤로 가기, 함수 호출 기록(콜 스택) 등에 활용
