# **Strategy (전략 패턴)**

* #### **같은 목적을 수행하는 여러 방법을 각각 클래스로 분리해 두고 실행 중 자유롭게 갈아끼우는 패턴**
* #### **커맨드는 요청 자체를 객체로 만들어 나중에 실행하거나 취소하는 데 집중하지만 전략은 같은 일을 하는 다양한 방법을 객체로 만들어 실행 중에 방식을 교체하는 데 집중**
* #### **if-else / switch 구문을 안써도 되고 기존 코드 수정 없이 새 전략 추가 가능**
